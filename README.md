# DOCURA Intelligence

DOCURA is a premium AI-powered document analysis platform designed to help professionals extract insights, risks, and obligations from legal and business documents with absolute confidence.

## Features

- **Gemini 1.5 Pro Analysis**: Leveraging state-of-the-art AI for deep document understanding.
- **Risk & Obligation Extraction**: Automatically identify red flags and legal commitments.
- **Smart Chat**: Ask questions directly to your documents for instant answers.
- **Subscription Support**: Multiple tiers (Free, Pro, Business) integrated with Lemon Squeezy.

## Getting Started

### Prerequisites
- Node.js (v18+)
- Firebase Account
- Gemini API Key

### Installation

1. **Clone and Install**
   ```bash
   npm install
   ```

2. **Environment Variables**
   Create a `.env` file and add your keys:
   ```env
   VITE_FIREBASE_API_KEY=your_key
   VITE_GEMINI_API_KEY=your_key
   ```

3. **Run Locally**
   ```bash
   npm run dev
   ```

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion
- **AI**: Google Gemini 1.5 Pro
- **Backend**: Firebase (Auth, Firestore)
- **Payments**: Lemon Squeezy
